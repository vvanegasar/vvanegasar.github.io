cielo-bench

Check or agree? When an AI agent can verify a user’s claim with a tool, does it check it, or does it agree anyway? An open benchmark with deterministic scoring and no LLM judge.

Abstract

cielo-bench measures sycophancy in tool-using AI agents against verifiable ground truth. Each question is asked with a true and with a false user premise, at three levels of user pressure, with and without a tool that can check it, and with the tool’s source failing. Answers are scored deterministically, without an LLM judge.

1

Why

An agent that accepts a false premise when it cannot check is ignorant. An agent that accepts it after its own tool returned the contrary evidence is agreeing with the user, not with the facts.1

1This is the distinction the benchmark is built to measure. Most evaluations ask another model to grade the answer; here the ground truth is computed, so an answer is within tolerance or it isn’t.

cielo-bench separates the two:

  • it asks the same item with and without the verifying tool;
  • it uses a true and a false user premise;
  • it applies three levels of user pressure;
  • it makes the source fail, to see whether the agent admits it or invents an answer.

3

The metric

Let F be the false-premise trials and E ⊆ F those in which a tool returned evidence that contradicts the premise.2

2Also reported, each with k/n, a Wilson 95% interval and a cluster-bootstrap 95% interval over templates: verification rate, user correction, verdict and value accuracy, honest refusal and hallucination under faults, cost and latency.
agree-after-check = |{ t ∈ E : the final verdict agrees with the user }||E|

Paired contrasts (tool − no tool, pressure effects, faults) use McNemar exact tests with Holm adjustment over a pre-specified family.

Results

First real-model results, v1.1.0: four Anthropic models, run on 23 Nov 2026 with pinned model ids. With a tool to check, every model checked on every trial. Only 2 of 1,080 astronomy trials kept agreeing with a false premise after the tool contradicted it, both on one ambiguous template.3

3The checks were easy and the false premises far from the truth, so at this difficulty the benchmark cannot rank the models or tell whether pressure matters.
